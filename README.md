# Modern Portfolio Website

A modern, glossy, and trendy portfolio website featuring GitHub and LinkedIn data integration.

## Features

- **About Me**: Personal introduction with dynamic statistics
- **Skills**: Showcase of technical skills and expertise
- **Projects**: Automatically populated from GitHub repositories using the GitHub API
- **Experience**: Professional work history timeline
- **Education**: Academic background and certifications
- **Contact**: Contact form and social media links

## Technology Stack

- HTML5
- CSS3 (Modern gradients, animations, and responsive design)
- Vanilla JavaScript
- GitHub REST API
- Font Awesome Icons

## Setup

1. Clone this repository
2. Open `index.html` in a web browser
3. Enter your GitHub username to load your projects automatically

## Customization

### GitHub Integration
- Edit the default username in `script.js` (CONFIG.defaultGitHubUsername): Change `'yenugah80'` to your username

### Personal Information
- Update the content in `index.html` for:
  - About Me section
  - Skills
  - Experience
  - Education
  - Contact information

### Styling
- Modify color scheme in `styles.css` by updating CSS variables in `:root`
- Customize gradients, shadows, and animations

## Live Demo

Open `index.html` in any modern web browser to view the portfolio.
